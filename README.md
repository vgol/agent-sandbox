# agent-sandbox
Giving a try to popular agentic harnesses

## Development container

Open this repository in VS Code with the Dev Containers extension installed, then
run **Dev Containers: Reopen in Container** from the command palette.

The container uses a generic Ubuntu development image with Python editor support.
It does not install or pin a Python runtime; choose and set up the runtime needed
by your agent separately.

Python caches, virtual environments, build artifacts, and local `.env` files are
excluded by `.gitignore`. This project is licensed under Apache 2.0; see `LICENSE`.
